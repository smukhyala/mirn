# Harvested copy

The prose lifted verbatim out of `src/mirn_app/static/` before that package was deleted: the five
`BEAT_CLAIMS` arrays, the masthead standfirst, and Beat 0.

It is here rather than in `web/` because it has been consumed. Every one of these paragraphs either
survives inside a page under `web/notes/` or was deliberately reframed, and a draft sitting in the
product tree next to the thing that superseded it is just a second version nobody is maintaining.

Kept because it is the record of what the teaching pages were adapted from, and because the
adaptation was not always a copy — page 8's opening, page 9's placebo framing and page 7's
"note on the state of the field" all changed meaningfully on the way across.
