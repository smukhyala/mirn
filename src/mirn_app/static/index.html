A measurement instrument

How much did the robot disturb people?

The field usually answers this by running a trajectory predictor with the robot's future zeroed out, then subtracting what the person actually did. That number is partly the robot's real effect and partly the predictor's own error, wearing a causal label. This page runs the same crowd twice — once with a robot, once without — and shows what changes when the comparison is honest.

All data on this page is synthetic.

The paired rollout

One crowd, run twice from the same seed and the same exogenous noise: once with a robot in the middle of the box, once with no robot at all. Because everything else is held identical, the difference between an agent's two paths is the robot's causal effect on it — no forecaster involved.
