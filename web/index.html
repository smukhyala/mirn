A bench for one question

How much did the robot move the crowd?

Everything on this page is simulated. The crowd is a social-force model — invented people obeying invented rules — and no number here is a measurement of real pedestrians. What is real is the ruler: the same room is run twice, once with a robot and once without, from the same starting positions and the same random wobble, and the difference between a person's two paths is the robot's effect on them.

How every number here is worked out

Start here

  • A robot nobody notices Nobody here reacts to the robot, so the honest answer is exactly zero. Watch what the forecaster reports beside it.
  • Four people, then forty-four Press Run. Watch the reading and the ordinary difference between two runs of the same room grow together as the room fills.
  • A robot that leans harder Press Run. Only how much space the robot demands is changing. Watch the crowd's real displacement climb, and watch the forecaster's line not follow it.
  • A crowd that fidgets Press Run. Only the crowd's aimless wobble is changing, and nobody here reacts to the robot, so its real effect stays flat at nothing. The forecaster keeps reporting one.

Simulated crowd. Every number below comes from a model.

  • A person, in the run with the robot
  • The same person, in the run without it
  • The distance between those two, which is the robot's effect on that person
  • The robot
  • A path walked with the robot in the room
  • The same path, walked without it

Switch off the setting that lets people notice the robot and every pair lands on top of itself, because then the robot changes nothing and there is no distance left to draw.

Two of the seven measurements below need the run-to-run band. This live preview does not measure it, so those two are left out here rather than shown with no zero to judge them against. Each tile opens on the assumption behind its number; the working sets out the arithmetic for all of them.
