A bench for one question

How much did the robot move the crowd?

All simulated. The crowd is an invented model of pedestrians, invented people obeying invented rules, so no number here is a measurement of real pedestrians. The ruler is real.

What this is

A robot walks through a fake crowd. Different rulers disagree about how much it disturbed them. This page is where you find out which ruler is lying.

  1. Set up the crowd Sliders in Settings: how many people, how pushy the robot is, how fast everyone walks.
  2. Press Run The same room plays twice: once with the robot in it, once without. Same starting spots, same random wobble.
  3. Compare the tiles Each tile is one way of measuring what the robot did. They will not agree, and that disagreement is the point.

Why twice? The only way to know what the robot did to somebody is to see the same person walk without it. A real corridor never gives you that second run. This one does, which is why a made-up crowd can teach something a real one cannot.

How every number here is worked out

Start here

  • A robot nobody notices Nobody here reacts to the robot, so the true answer is zero. Watch what the forecaster says anyway. It is the ruler that only ever gets to see one run.
  • Four people, then forty-four Press Run. As the room fills, watch the reading and the normal gap between two runs grow together.
  • A robot that leans harder Press Run. Only the robot's pushiness changes. The real effect climbs; the forecaster's line does not follow.
  • A crowd that fidgets Press Run. Only the crowd's wobble changes. Nobody reacts to the robot, so the real effect stays at nothing. The forecaster keeps reporting one.
  • The referee drill Call whether the robot disturbed the crowd before you are shown the second run, then see what the room actually did.
  • Does this crowd walk like a real one? The one page with real people on it. Hand it a recording and it tunes the fake crowd to walk like them. It shows no disturbance number and cannot work one out.
  • The method card Bring your own way of measuring disturbance. Answer five questions about it, then see what it reads on a world where the true answer is nothing.

Stage

Both runs at once. Filled dots are the crowd with the robot; hollow dots are the same people without it. Every number below comes from this model, not from real people.

  • A person, in the run with the robot
  • The same person, in the run without it
  • The distance between those two, which is the robot's effect on that person
  • The robot
  • A path walked with the robot in the room
  • The same path, walked without it

Switch off "People notice the robot" and every pair lands on top of itself: the robot changes nothing, so there is no distance left to draw.

One tile, one ruler. Open any tile to see what it assumes and what it would read if the robot had done nothing at all. The forecaster is the ruler that guesses where each person was headed and measures how far off they ended up. It never sees the run without the robot, which is why it can be fooled. Two measurements stay blank until you press Run, because they need repeat runs this live preview does not do. The working sets out the arithmetic for all of them.
