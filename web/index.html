The same room, twice

One crowd, run twice from the same starting positions and the same random wobble: once with a robot crossing the room, once with no robot at all. Because everything else is held identical, the difference between a person's two paths is the robot's effect on them, with nothing predicted or guessed at.

Turn off People notice the robot and the gap collapses to exactly zero. The robot is still there and still moving; nobody is responding to it. That is what a true effect of nothing looks like, and it is the thing every measurement on this site has to reproduce.

Everything here is simulated. The crowd is a model, not a recording of real people, and no number on this page is a measurement of anything that happened.
