# The paired rollout

One crowd, run twice from the same starting positions and the same random wobble: once with a robot standing in the middle of the room, once with no robot at all. The robot pushes people aside as they pass; nobody in this crowd is deciding to move, and the robot never moves either. Because everything else is held identical, the difference between a person's two paths *is* the robot's effect on them, with nothing predicted or guessed at.

Nothing here is a real robot or a real corridor. That is the point. This crowd is invented, so we know exactly what the robot did to it — which makes it the one place where a way of measuring disturbance can be handed a question whose answer is already known, and caught getting it wrong. Every method on this page is graded that way before anyone trusts it on real data.
